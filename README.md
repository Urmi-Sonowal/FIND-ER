## 📖 Overview

FIND-ER is a web-based Lost & Found Management System developed to simplify the process of reporting, tracking, and recovering lost items within a college campus.

The platform provides dedicated interfaces for both students and administrators, enabling efficient item management, status tracking, notifications, and recovery workflows.

This project was developed as a frontend-focused application using HTML, CSS, and JavaScript.

## 🔄 Workflow

1. Student logs into the platform.
2. Reports a lost or found item.
3. Item details are stored locally.
4. Administrators review submissions.
5. Matching and verification process occurs.
6. Students receive notifications.
7. Item is marked as recovered and collected.
